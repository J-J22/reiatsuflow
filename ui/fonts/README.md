Bundled fonts, so the app looks the same on any system:

- `PressStart2P.ttf`: Press Start 2P by CodeMan38, SIL Open Font License 1.1 (`OFL-PressStart2P.txt`).
- `Rubik.ttf`: Rubik (variable) by the Rubik project authors, SIL Open Font License 1.1 (`OFL-Rubik.txt`).
- `icons.ttf`: a 50-icon subset of Material Symbols Rounded by Google, Apache License 2.0
  (https://www.apache.org/licenses/LICENSE-2.0). Rebuild with `tools/build_icons.py`.
